# 符号恢复

用途：给 stripped 二进制里的无名函数恢复语义名称。

程序步骤见 `binary-symbol-recovery` 技能；本页给判据与识别模式。

## 三步法

```text
第一步 内部特征：魔数常量表 > 字符串常量 > 代码结构
第二步 交叉引用：成对调用 + 参数/返回值形态
第三步 收集检索：本地推理优先，不足时才搜魔数/代码模式/唯一字符串
```

**顺序不能颠倒**。先看常量能直接命名，直接省掉后面两步；反过来先搜网络，容易搜出一堆相似但不相关的实现。

## 成对调用识别表

无符号时，函数的作用往往由它的"另一半"暴露：

| 配对 | 识别依据 |
|---|---|
| 分配 / 释放 | 取 size 返指针 ↔ 取同一指针 |
| 加锁 / 解锁 | 同一锁对象进出 |
| 打开 / 关闭 | path + flags 返 handle ↔ 取 handle |
| 线程创建 / 汇合 | 出参 + attr + func + arg ↔ tid + 出参 |
| 网络套接字创建 | 固定常量调用形态（地址族/类型/协议三常量） |
| 连接 / 绑定 | 地址结构长度参数为固定值 |
| 内存拷贝 / 置零 | 三参数形态 / (ptr, 0, 常量) 形态 |
| 字符串比较 | 返回值与 0 比较后分支 |

## 返回值模式

| 模式 | 含义 |
|---|---|
| 出错返回 -1 | 文件 / 网络类操作 |
| 失败返回 NULL | 内存分配 |
| 成功返回 0 | 通用成功约定 |
| 返回长度并被喂给拷贝函数 | 该函数产出的长度 |

## 参数形态线索

参数个数与类型本身就是信息：

- 三参数 `(dst, src, n)` → 拷贝类
- `(ptr, 0, 常量)` → 置零类
- `(fd, &struct, 固定小整数)` → 网络地址结构类
- `(int, int, 0)` 固定常量三元组 → 常见于套接字创建

## 置信度纪律

| 置信度 | 判据 |
|---|---|
| 高 | 命中算法常量表；或成对调用 + 参数形态双重吻合；或字符串直接点明用途 |
| 中 | 仅成对调用或仅参数形态吻合 |
| 低 | 仅代码结构相似，属待验证假设 |

**不允许**只给名称不给证据；**不允许**把低置信度写成确定结论。

## 常见坑

| 坑 | 处理 |
|---|---|
| 只看函数内部，忽略调用方 | 调用点常比函数体更能说明参数语义 |
| 把"相似结构"当"同一算法" | 结构相似只能给低置信度；必须用输入输出验证 |
| 忽略编译器优化 | 内联、尾调用优化会打乱成对调用的可见性；换优化等级或看更上层调用 |
| 把导入表当唯一线索 | 静态链接的程序没有导入表，靠常量与结构 |
