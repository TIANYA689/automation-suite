# 结构体恢复

用途：从内存访问模式重建 struct / class 布局。

程序步骤见 `binary-symbol-recovery` 技能；本页给推断规则与判据。

## 基本流程

```text
1. 找指针参数（潜在结构体指针）
2. 采集访问模式：offset / size / access / type
3. 遍历调用方：看传参形态与调用前后对该对象的操作
4. 遍历被调方：看参数如何被使用、是否被转交
5. 聚合推断：按 offset 排序，大小 = 最大偏移 + 末字段大小
```

## 访问模式记录格式

```c
*(a1 + 0x10)              // 偏移 0x10
*(_DWORD *)(a1 + 8)       // 32 位
*(_QWORD *)(a1 + 0x20)    // 64 位
*(a1 + 8 * i)             // 数组，元素 8 字节
*(*a1 + 0x10)             // 嵌套：首字段是指针
```

## 字段类型推断规则

| 观察到的用法 | 推断类型 |
|---|---|
| 被当函数指针调用 | 函数指针 |
| 传给字符串函数 | 字符串指针 |
| 与常量比较 | 枚举 / 标志位 |
| 自增自减 | 计数 / 索引 |
| 偏移 0 是函数指针表 | 虚表（C++ 对象） |
| next / prev 成对出现 | 链表节点 |
| 引用计数字段 | 引用计数对象 |
| 调用点刚分配固定大小 | 该大小即结构体近似大小 |
| 被转交给另一函数 | 可能是嵌套结构 |

## 调用方提供的线索

调用方往往比被调方更能说明字段语义：

- 传参形态：直接传指针 / 取地址 / 刚分配的一块内存。
- 调用前的初始化：`*v = 0` 说明偏移 0 需要清零。
- 调用后的赋值：`*(v + 8) = callback` 说明偏移 8 是回调指针。
- `malloc(N)` 的 N 与推断大小互证。

## 判据

**结构体大小 = 最大偏移 + 末字段大小。**

这个公式在以下情况失效，需要特别处理：

- 存在间接索引（`base + index * size`）——改按数组元素建模。
- 结构体尾部有柔性数组——大小需按实际分配推断。
- 字段被按位访问——需还原位域布局。

## 常见坑

| 坑 | 处理 |
|---|---|
| 把局部变量当成结构体字段 | 只统计通过同一指针基址访问的模式 |
| 混淆了 `a1` 与 `*a1` | 前者是结构体指针，后者说明首字段是指针，字段偏移要加一层 |
| 忽略对齐填充 | 偏移出现"跳空"通常是填充，标注为保留字段 |
| 结构体大小算小 | 检查是否只分析了部分调用方；扩大调用簇再聚合 |
| C++ 对象当成 C 结构体 | 先找构造/析构/虚表写入点，偏移 0 是虚表指针 |
