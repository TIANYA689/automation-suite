# 算法盲识别

用途：拿到一段未知的加密/哈希实现，或一串未知密文，在没有名称线索的情况下反推算法。

这是符号恢复之外的独立能力：**符号恢复是"给函数命名"，盲识别是"给算法定性"**。

## 四个层次

按证据强度递进，能用低层解决就不上高层。

### 第一层：静态特征

查表命中即高置信度：

- S-Box 与置换表（AES、DES、SM4 等各有固定表）
- 哈希初值与轮常量（MD5、SHA 系列的固定字）
- 魔数（压缩格式、可执行格式）
- 编码表（Base64 标准表与自定义表）

完整常量表见 `skills/binary-symbol-recovery/references/algorithm-fingerprints.md`。

### 第二层：统计特征

没有查表命中时，用统计量缩小范围：

- 字节熵：高熵可能是加密或压缩；低熵可能是编码或明文。
- 长度规律：块密码输出长度是块大小整数倍。
- 字符集：区分 hex / base64 / 原始二进制。

### 第三层：结构特征

- 块边界：相同明文块在 ECB 模式下产生相同密文块（这是 ECB 的判定依据）。
- 分组链接痕迹：CBC 下修改前一块会破坏后一块。
- 轮函数结构：查表密度、位运算组合形态。

### 第四层：操作特征

- XOR 频率分析：单字节 XOR 可暴力恢复密钥。
- 重合指数 / Kasiski：多字节重复密钥 XOR 的密钥长度恢复。
- 差分：已知明文对推密钥。

## 关键判据

| 观察 | 结论 |
|---|---|
| 相同明文产生相同密文 | 无 IV 或固定 IV；可能是 ECB |
| 修改一个字节导致后续全部变化 | 链式模式（CBC 类） |
| 输出长度等于输入长度 | 流密码或 XOR 类 |
| 输出长度是 16 的整数倍且大于输入 | 块密码 + PKCS7 填充 |
| 命中 S-Box 但输出与标准不符 | 变体实现（改了初值/轮数/表） |

## 变体处理

命中常量表只说明"该算法实现存在"，**不说明它就是当前使用的那一个**。必须回到调用链确认。

变体实现（改初值、改轮数、改表）不会命中查表，此时靠结构相似度给低置信度，再用差分验证。

## 纪律

- 形态匹配只给可能性排序，不给结论。
- 出现多个算法常量时，按调用顺序理清流水线（例如"先压缩后加密"）。
- 无法确定时如实标注置信度，写清还需要什么证据。
