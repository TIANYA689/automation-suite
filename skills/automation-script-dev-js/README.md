# automation-script-dev-js

JavaScript/Node.js 自动化脚本开发 Skill，支持青龙面板及 Surge、Loon、QuanX 等平台。

## 当前版本

- 版本：`2.0.0`
- 主模式数量：7
- 子场景数量：8
- 指向 Python Skill 的跨语言引用已适配 Python `6.1.0`。
