# automation-architect

自动化项目的需求分析、技术选型与专业 Skill 路由入口。

## 当前版本

- 版本：`3.3.0`
- Python 自动化 Skill：13 个主模式、37 个子场景
- JavaScript 自动化 Skill：8 个主模式、16 个子场景

## 编号约定

- Python 模式使用连续编号 `P1-P13`。
- Python 子场景使用 `P主编号.序号`。
- JavaScript 模式使用连续编号 `P1-P8`。
- JavaScript 子场景使用 `P主编号.序号`。
- 跨语言映射以 `SKILL.md` 的“跨语言通用模式索引”为准。

开发前必须执行 Pattern 覆盖门禁：语言技能中定义的每个主/子 Pattern 均标记为 `apply`、`skip` 或 `pending`；编码前清零 `pending`，交付前为所有 `apply` 补齐实现与验收证据。
