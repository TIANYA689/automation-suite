# automation-architect

自动化项目的需求分析、技术选型与专业 Skill 路由入口。

## 当前版本

- 版本：`3.1.0`
- Python 自动化 Skill：12 个主模式、21 个子场景
- JavaScript 自动化 Skill：7 个主模式、8 个子场景

## 编号约定

- Python 模式使用连续编号 `P1-P12`。
- Python 子场景使用 `P主编号.序号`。
- JavaScript 模式使用连续编号 `P1-P7`。
- JavaScript 子场景使用 `P主编号.序号`。
- 跨语言映射以 `SKILL.md` 的“跨语言通用模式索引”为准。
