# automation-script-dev-py

Python 自动化脚本开发 Skill，支持青龙面板和本地运行。

## 当前版本

- 版本：`6.1.0`
- 主模式数量：12
- 子场景数量：21

## 模式组织原则

- 按功能域排列关联模式。
- 相似模式合并到编号更靠前的主模式。
- 被合并能力使用 `P主编号.序号` 标识，避免重复入口。
- 完整规则、代码示例和合并映射以 `SKILL.md` 为准。

## 主模式

| 功能域 | 主模式 |
| --- | --- |
| 代理与防封 | P1、P2 |
| 账号与授权 | P3、P4 |
| 注册与验证 | P5 |
| 网络与安全 | P6、P7 |
| 任务编排 | P8 |
| 配置与组织 | P9、P10 |
| 日志与通知 | P11、P12 |
