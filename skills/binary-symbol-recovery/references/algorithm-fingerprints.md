# 算法常量指纹

命中下列常量即可高置信度判定算法族。搜索时用十六进制字节序列，注意目标架构的字节序。

## 哈希与校验

| 算法 | 特征常量 | 说明 |
|---|---|---|
| MD5 | `0x67452301` `0xEFCDAB89` `0x98BADCFE` `0x10325476` | 四个初始状态字，小端存储时字节序反转 |
| SHA-1 | `0x67452301` `0xEFCDAB89` `0x98BADCFE` `0x10325476` `0xC3D2E1F0` | 比 MD5 多第五个字 |
| SHA-256 | `0x6A09E667` `0xBB67AE85` `0x3C6EF372` `0xA54FF53A` 等 8 个字 | 8 个初值 |
| SHA-512 | `0x6A09E667F3BCC908` 等 8 个 64 位字 | 64 位初值 |
| CRC32 | `0xEDB88320` | 反射多项式；非反射为 `0x04C11DB7` |
| CRC16-CCITT | `0x1021` | 常见于协议校验 |

## 对称加密

| 算法 | 特征 | 说明 |
|---|---|---|
| AES | S-Box 首字节 `0x63, 0x7C, 0x77, 0x7B, 0xF2, 0x6B, 0x6F, 0xC5` | 256 字节表；逆 S-Box 首字节 `0x52, 0x09, 0x6A` |
| AES | 轮常量 `0x01, 0x02, 0x04, 0x08, 0x10, 0x20, 0x40, 0x80, 0x1B, 0x36` | Rcon |
| DES | 置换表 + S-Box 8×64 | 查表密集 |
| SM4 | `0xA3B1BAC6` `0x56AA3350` `0x677D9197` `0xB27022DC` | 四个系统参数 |
| ChaCha20 | `"expand 32-byte k"` 常量串 | 亦见 `"expand 16-byte k"` |
| Salsa20 | `"expand 32-byte k"` | 与 ChaCha 共用常量串，靠轮函数结构区分 |
| RC4 | 256 字节 S-Box 初始化循环 + 索引交换 | 无固定常量，靠循环结构识别 |

## 编码与压缩

| 算法 | 特征 |
|---|---|
| Base64 | 标准表 `ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/`；自定义表改此串 |
| Base64url | 上表末两位换成 `-_` |
| Zlib | 流首字节 `0x78`，次字节常见 `0x01` `0x9C` `0xDA` |
| Gzip | 魔数 `0x1F 0x8B` |
| LZMA | 属性字节 + 字典大小字段 |
| UPX | 节名 `UPX0` `UPX1`，或魔数 `UPX!` |

## 非对称与派生

| 算法 | 特征 |
|---|---|
| RSA | 大数运算 + 模幂循环；公钥 PEM 头 `-----BEGIN PUBLIC KEY-----` |
| 曲线加密 | 曲线参数常量串（如 `secp256r1` 的 p、a、b）；基点坐标 |
| PBKDF2 | 迭代次数常量 + HMAC 调用链 |
| bcrypt | 盐串前缀 `$2a$` `$2b$` `$2y$` |
| Argon2 | 参数块 + `$argon2id$` 前缀 |

## 混淆/保护特征

| 特征 | 可能含义 |
|---|---|
| 大量 `xor` + 循环移位 + 常量 | 自定义/变体加密，或 XOR 常量加密（如 oxorany 风格） |
| 控制流分发循环 + 状态变量 | 控制流平坦化（OLLVM FLA） |
| 指令替换为等价算术序列 | 指令替换（OLLVM SUB/BCF） |
| 大数组 + switch 分发 + 虚拟 PC | 虚拟机保护（VMP），需转向动态分析 |
| 字符串全为密文 + 运行时解密 | 字符串表加密 |

## 使用纪律

- 命中常量只证明"该算法实现存在"，**不证明**它就是当前签名/校验所用的算法。必须回到调用链确认。
- 变体实现（改初值、改轮数、改 S-Box）不会命中常量表，此时靠结构相似度 + 差分验证。
- 出现多个算法常量时，按调用顺序理清"先压缩后加密"之类的流水线。
