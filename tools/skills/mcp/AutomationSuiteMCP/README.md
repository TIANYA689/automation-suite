# AutomationSuiteMCP

本 MCP 提供 automation-suite 的工具化入口。

## Tools

- `automation_route`
- `list_skills`
- `read_skill`
- `script_inventory`
- `py_decrypt_probe`
- `js_deobfuscate_probe`
- `py_obfuscate`
- `js_obfuscate`
- `validate_script_delivery`

## Run

```powershell
uv run --project tools/skills/mcp/AutomationSuiteMCP python tools/skills/mcp/AutomationSuiteMCP/automation_suite_mcp.py
```
